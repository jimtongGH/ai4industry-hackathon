# React GUI for the Hackathon of the ai4industry 2024 Summer School

## To Run the Project
1. Install the required packages
```
npm install --legacy-peer-deps
```

2. Change the `const simu = x;` in the file `src/App.js` line 5 with the number of your group i.e. the simulation you are using e.g 1, 2, 3 ect.

3. Run the Project
```
npm start
```

**Note that [ai4industry-gui-spring](https://gitlab.emse.fr/ai4industry/ai4industry2024-gui/ai4industry-gui-spring) project must be running to get the data**
